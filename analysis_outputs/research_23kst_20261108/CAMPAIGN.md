## 평가 및 후보 선택

기존 연간·계절 평가 5개와 2022년 6월부터 2024년 12월 기점까지의 분기 평가 11개를 사용한다. 분기 구간끼리는 겹치지 않지만 기존 5개 평가와는 겹친다. **16개의 독립 검증으로 해석하지 않는다.** 탐색 정답은 2025년 3월 1일까지다. 각 보정 학습은 실제 생성 모델의 학습 종료 뒤에 발생했으면서 해당 외부 학습 시점 이전인 OOF 정답만 사용한다. 반복된 목표 시각은 해당 학습 부분집합 안에서 중복 가중치를 보정한다.

새 결과를 보기 전에 다음 기준을 고정한다.

- 3시드 평균의 분기 W/raw 평균이 0.5% 이상 개선되고, 11개 중 7개 이상 개선되며, 최악 분기 악화는 2% 이하다. 각 그룹의 분기 합계 W/raw는 1.0 이하다.
- 각 시드가 따로 평가한 분기 합계 오차도 기초 예측보다 개선돼야 한다.
- 기존 5개 평가의 평균도 개선되고 3개 이상 개선되며 최악 악화는 2% 이하다.
- 혼합 계수 alpha는 primary 정답으로만 결정하고 recent에 그대로 적용하며 최소 0.02여야 한다. 최고 제출 예측 대비 두 기간 모두 상대 W가 0.01% 이상 개선되고, 각 기간 안의 어느 그룹도 0.1% 초과 악화하지 않아야 한다.
- 최소한 3시드가 완료된 설정 12개, 기초 모델별 3개 이상이 있어야 후보를 선정한다.
- 적격 설정은 최악 그룹의 분기 합계 비율, 분기 평균 비율, 기존 평가 평균 비율, 혼합 primary/recent 비율, ID 순으로 비교한다. 기초 모델별 최대 1개, 전체 최대 3개를 같은 기초 모델 비중으로 혼합한다. 혼합 후에도 고정된 기준을 다시 확인한다.

primary뿐 아니라 recent와 분기 평가도 후보 선택에 사용한 **개발 자료**다. 모든 과거 기간은 이미 노출돼 있다. 시간 순서 OOF와 시드 반복은 자료 누출과 실행 변동을 점검하는 방법이지 독립 홀드아웃이나 공식 성능 개선의 증명이 아니다. 기본 생성 모델의 seed 0을 고정한 보정 시드 반복만으로 전체 생성 모델의 학습 안정성이 검증됐다고 표현하지 않는다.

후기 2025년 3–5월 정답은 후보 및 해당 후기 예측을 고정한 뒤에만 평가한다. 후기 결과를 보고 후보·혼합 계수·규칙을 다시 선택하지 않는다. 배포 학습에서 사용 가능한 정답의 시점과 별도 후기 평가 라벨을 명확히 구분한다.

## 실행과 안전한 재개

새 코드는 `submission/score_push_23kst`, 새 산출물은 `analysis_outputs/research_23kst_20261108`에 둔다. 기존 10시간 및 22시간 캠페인의 소스·manifest·state·실패 원문·제출 파일은 그대로 보존한다. NumPy 불리언 직렬화 오류는 **새 코드에서만** 수정하고, 적격값이 참인 경로와 비유한 수 거부, 원자 저장을 학습 전에 검사한다.

실행은 동시에 하나의 학습만 허용하고 CPU 4개, BLAS 1스레드를 사용한다. 이전 캠페인과 새 작업의 기록된 PID/start_ticks/boot_id 및 프로세스 그룹을 실제 프로세스와 대조한다. `STOP`이 있으면 명시적 중단으로 취급하며 해제하거나 자동 재개하지 않는다. 완료한 실험은 다시 학습하지 않는다. 저장 공간이 부족하면 기존 산출물을 삭제하는 대신 체크포인트를 보존하고 중단 사유를 기록한다.

실행 전 고정한 `controller_manifest.json`, `launch_contract.json`, `protocol.json`과 독립 준비 감사가 기준이다. 컨트롤러만 중단된 경우 같은 manifest와 state-dir로 재개하며 살아 있는 worker는 인계한다. 실행 중 소스나 manifest를 바꾸지 않는다.

```bash
/workspace/.venvs/oibc-2026/bin/python /workspace/OIBC_2026_DATA/submission/score_push_23kst/controller.py \
  --manifest /workspace/OIBC_2026_DATA/analysis_outputs/research_23kst_20261108/controller_manifest.json \
  --state-dir /workspace/OIBC_2026_DATA/analysis_outputs/research_23kst_20261108/controller_state \
  --detach
```

전체 종료 이후 새 학습은 시작하지 않는다. 보고 전용 finalizer와 실제 프로세스 종료를 확인한 후 `final_verification_contract.json`에 고정한 독립 검증기를 외부에서 실행한다. `CHECKPOINT_ONLY`, 후보 없음, 예산 부족, 형식 검증을 마친 미제출 후보를 구분한다. 파일이 없거나 해시가 다르면 성공으로 추정하지 않는다.
