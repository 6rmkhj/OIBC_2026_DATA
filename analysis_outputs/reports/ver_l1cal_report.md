## 0. 판정 요약

주장은 **두 부분**으로 나뉜다. (a) "L1 / SMP·k 가중 L1 학습이 L2보다 W를 낮춘다", (b) "가중 중앙값 보정을 적용하면 W가 (추가로) 낮아진다".

* (a) 방향은 맞지만 **크기가 seed·스레드 노이즈와 같은 자릿수**다. 보고서의 L1 대 L2 차이는 −1.1%(E1_l1) / −1.6%(E1_l1w)인데, L1w seed 3개의 범위만으로도 12.44~12.55%(W 기준 0.9%)이고, L2는 seed 1개만 돌려 비교했다. 같은 설정으로 L2·L1·L1w 를 seed 3개씩 재학습한 결과(3절) L1 < L2 는 유지되지만 평균 차이는 1.4~1.5%(L1w 는 1.3%, p≈0.1)이고, 보고서의 E1_l1w 12.46%는 L1w 5개 draw(12.44~12.64, 중앙값 12.55) 중 하단의 운 좋은 값이다(보고서 기본 모델이 LightGBM 기본 seed draw 임을 4절에서 확인). 가중 L1은 비가중 L1보다 낫지 않고(12.53 vs 12.52) 분산만 2.5배다.
* (b)는 **보고서 자체의 수치가 반박**한다. 가중 중앙값 보정은 per-site L2 기준선(E0_site)에서만 크게 유효(+8~18%)하고, 최종 추천 모델(E7_mix_site10, E4_blend50)에서는 계절 교차(half)에서 **−1.1 ~ −1.8% 악화**, model_validation E5에서도 E4_blend50에 적용 시 **+2.4% 악화**(9.053e8 → 9.265e8)다. 두 보고서 모두 "최종 모델에는 보정을 적용하지 말 것"을 권고한다. L1 단일 모델(E1_l1, E1_l1w)에 한해서만 +0.2~0.4%(half) / +1.1~1.4%(wk)의 작은 이득이 있는데, 이것은 폴드별로 부호가 바뀌고(half 폴드0: −0.16~−0.72%, 폴드1: +1.1~+1.4%) 전부 G1의 일관된 약 2.3% 과대예측(계수 0.971~0.983)을 되돌리는 효과이며 G2에서는 −1.9~+0.9%로 무작위다.
* 따라서 "L1 + 가중 중앙값 보정"이라는 **조합이 W를 낮추는 메커니즘이라는 주장은 기각**한다. 근거가 되는 숫자는 모두 정확히 재현되지만(아래 1~2절), 그 숫자들이 말하는 것은 "pooled 모델로의 전환(−22%)과 앙상블(−3%)이 이득의 전부이고, 목적함수 L1은 노이즈 수준의 소폭 이득, 보정은 최종 모델에서 손해"다.

* **재현성**: 내 L1w seed 2 = 2,149,382,586 ↔ 보고서 E1_l1w_s2 = 2,149,382,589 (완전 일치) → 데이터·피처·설정은 동일하다. 그런데 seed 0은 보고서의 E0_pool(12.661)·E1_l1(12.521)·E1_l1w(12.460)을 재현하지 못한다(12.747 / 12.560 / 12.635). 보고서의 기본 모델들은 `random_state` 인자가 추가되기 전(LightGBM 기본 seed)에 학습된 것으로 보인다(4절 stage C에서 확인). 즉 보고서의 "E1_l1w 12.46 = 단일 최상"은 **5개 draw 중 가장 운이 좋은 쪽**(12.437~12.635의 하단)이고, 같은 설정의 중앙값은 12.55다.
* **L1 < L2 자체는 seed 를 바꿔도 유지된다**: L1 3개와 L2 3개는 범위가 겹치지 않고(L1 최대 12.560 < L2 최소 12.689), Welch t = −6.45 (p = 0.004). 평균 차이는 **1.4~1.5%**(W 기준 약 3.1e7, 0.1·W 환산 약 310만 원/년). 보고서 표현 "L1 −1.1%, L1+가중 −1.6%"는 각각 한 draw의 값이며, 평균적으로는 둘 다 약 1.3~1.5%다.
* **SMP·k 가중은 이득이 없고 분산만 키운다**: L1w 평균 12.548(내 3개)/12.531(전체 5개) vs L1 12.521/12.522 → 가중이 오히려 0.1~0.2% 나쁘고, seed sd 는 0.101 vs 0.041로 2.5배. L1w 대 L2의 Welch t = −2.70 (p = 0.096, 유의하지 않음), 최악 L1w draw(12.635) 대 최선 L2 draw(12.661)의 차이는 0.21%에 불과하다. 보고서가 가중 L1을 추천 설정으로 채택한 근거(12.46 vs 12.52)는 seed 노이즈(sd 0.1)보다 작다.
* **재학습 모델에 대한 가중 중앙값 보정**(전역 계수, 2-fold): L2 half −0.95~−1.09% / wk +0.22~+0.39%, L1 half +0.19~+0.64% / wk +1.35~+1.50%, L1w half +0.29~+0.46% / wk +1.06~+1.48%. 적합 계수 a_G1 은 L1·L1w 모든 적합에서 0.970~0.983(안정적 과대예측), L2 는 0.998~1.017. 2절과 같은 그림: 보정 이득은 L1 의 G1 편향 되돌리기(+0.2~0.6%, 약 100만 원/년)에 그치고, L2에 얹으면 손해다.
* 규모 비교: per-site L2 → pooled L2 전환 −22.3%(0.1·W 환산 약 6,270만 원/년) ≫ 앙상블·블렌딩 −2.5~−5% ≫ **L1 목적함수 −1.4% ≫ 가중 중앙값 보정 +0.2~0.6%(L1 단일)·−1~−2%(최종 앙상블)**. "L1 + 보정"은 이득의 주된 원천이 아니다.

## 5. 판정과 정정

**refuted = true (confidence 0.7)** — 주장은 두 개의 서로 다른 효과를 하나로 묶었고, 그중 보정 부분은 보고서 자체의 수치에 의해 반박되며, L1 부분은 방향은 맞지만 크기가 noise 자릿수다.

1. "가중 중앙값 보정이 W를 낮춘다"는 **최종 추천 모델(E7_mix_site10, E4_blend50)에서 거짓**이다: 계절 교차 half −1.1 / −1.6%, E5(전반 적합→후반) −1.1 / −2.3%, 같은 계절 wk +0.2%(노이즈). L1 단일 모델에서만 +0.2~0.6%(half)이며 폴드에 따라 부호가 바뀐다. 두 보고서 모두 보정을 적용하지 말라고 권고하고 있으므로, 주장은 보고서의 결론과도 어긋난다.
2. "L1이 L2보다 낫다"는 **참이지만 1.3~1.5%**(W 약 3e7, 약 300만 원/년)이고, 보고서의 비교는 L2 seed 1개 vs L1w 의 운 좋은 draw 였다. 같은 설정 내 seed 분산(L1w sd 0.10pp ≈ W 0.8%)과 forecast_skill의 L2 모델(피처·학습창만 다른데 12.24%로 E1_l1w보다 1.4% 우수)을 함께 보면, 목적함수는 피처·학습창·앙상블보다 하위 요인이다.
3. "SMP·k 가중 L1"은 비가중 L1보다 낫지 않다(평균 12.53 vs 12.52, 분산 2.5배). 가중 L2는 L2보다 1.4% 나쁘다. 가중 자체를 권고 근거로 쓰면 안 된다.
4. 보정이 하는 일은 bottom-up L1 모델의 **구조적 G1 과대예측(계수 0.97~0.98)**을 되돌리는 것뿐이다. 이 편향은 "발전소별 조건부 중앙값의 합 ≠ 그룹 합의 중앙값"에서 오므로, 테스트 제출에서 L1 bottom-up 을 쓴다면 전역 계수 0.975 정도를 G1에 곱하는 것(또는 그룹 단위 L1 모델 E4 와 블렌딩)이 보정의 실질적 내용이다. 시간대·월별 계수는 불필요하다.

정정 제안(보고서 문구):
* model_validation_report 2절 "L1 계열이 L2보다 확실히 낫고" → "L1 계열이 L2보다 평균 1.3~1.5% 낫다(seed 3개 재학습 기준, L1w 는 p≈0.1 수준). 가중은 이득 없음."

* 주장 문장 자체를 "pooled L1 학습은 L2 대비 약 1.4% 낮은 W를 주고, 가중 중앙값 보정은 L1 단일 모델의 G1 과대예측에 한해 +0.2~0.6%를 추가로 줄 뿐 최종 앙상블에는 손해(−1~−2%)"로 바꿔야 한다.
