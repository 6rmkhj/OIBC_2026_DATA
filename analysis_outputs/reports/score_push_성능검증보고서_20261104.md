# OIBC 2026 추가 성능 연구·제출 후보 검증

새 제출 후보를 `submission/score_push_candidate/`에 생성했다. 두 개발 기간과 전체 연간 검증은 개선됐지만, 마지막 2025년 3–5월 확인 구간은 악화됐다. 따라서 **일관된 최근 성능 개선이나 실제 리더보드 상승이 입증된 후보로 보아서는 안 된다.** 기존 최고 제출은 보존했다.

사용자가 알려준 실제 점수는 기존 6,443,559,992, 이전 autoresearch 6,447,820,797이다. 실제 상승분은 4,260,805이며, 당시 순위는 160등, 1등은 6,500,000,000 초과였다. 새 후보는 아직 공식 채점되지 않았다. 이 보고서의 로컬 점수를 공식 점수나 향후 순위로 환산하지 않는다.

## 연구 방법과 변경 사항

카파시 autoresearch의 가설 제시 → 동일 평가 → 개선 유지/악화 폐기 → 기록 방식으로 진행했다. 초기 CPU 연구는 모델 하나씩 LightGBM 2스레드, BLAS 1스레드, Windows BelowNormal 우선순위로 실행했다. 이후 사용자의 자원 확대 요청에 따라 CPU 16스레드·BLAS 16스레드·Windows 보통 우선순위로 변경하고 별도 CatBoost GPU 환경을 추가했다. 외부 데이터는 사용하지 않았으며 동시 학습은 계속 한 개다.

| 실험군 | 결과 |
|---|---|
| 예보 변수 확장, 10시·17시 예보와 변화량, 물리 특성 | 양쪽 개발 기간에서 소폭 개선 |
| 발전소 식별·물리 특성을 추가한 발전소 모델 | 기존 bottom-up 대비 부진, 폐기 |
| 물리 정규화 LightGBM·작은 MLP·커널 모델 | 정규화 LGBM과 CF MLP가 보완 효과 |
| 모델 복잡도·시드·고정 혼합 정제 | 63-leaf 정규화 LGBM 3시드, MLP 3시드 선택 |
| 기상 관측소별 공간 예보 분포 | station LGBM 3시드 선택; station MLP 폐기 |
| 기존 cell 모델을 추가하는 마지막 무학습 혼합 | 최근 개발 기간 악화로 폐기 |

최종 모델은 확장 예보 LGBM, 물리 정규화 LGBM, 작은 CF MLP, 관측소별 공간 LGBM 각 3시드와 기존 bottom-up 예측의 고정 혼합이다. 학습에만 적합한 전처리·상수 열 제거를 사용했다. 발전량 정답을 예보 특성에 넣지 않았다.

정확한 혼합식:

```text
reference = 0.7642694482340047 * rich_direct
          + 0.23573055176599533 * bottom_up
refined   = 0.380705173762783 * reference
          + 0.41926809371483975 * normalized_LGBM
          + 0.2000267325223772 * CF_MLP
candidate = 0.7191528379552014 * refined
          + 0.2808471620447986 * station_LGBM
```

혼합 가중치는 첫 개발 구간에서 맞춘 뒤 최근 개발 구간에 그대로 적용했다. 모델 선택에는 두 개발 구간을 사용했다. 정제 단계에서 선택 규칙을 명확히 한 기록은 `refinement_wave/selection_rule_clarification.json`과 `clarified_results.json`에 보존했다. 이를 사전에 완전히 고정된 단일 비교로 포장하지 않는다.

## 시계열 평가

모든 경계는 KST이며 검증은 `시작 시각 < ts <= 종료 시각`이다. 날짜·월은 `ts - 1시간`, 피크 가중치는 실제 timestamp의 11~15시에 3, 나머지 1이다. 발전량이 없는 행은 정답 0으로 꾸미지 않고 제외했다.

| 구분 | 학습 종료 | 평가 기간 | 행 수 |
|---|---|---|---:|
| 첫 개발 | 2023-06-01 00:00 | 2023-06-01~2024-06-01 | 17,568 |
| 최근 개발 | 2024-06-01 00:00 | 2024-06-01~2025-03-01 | 13,104 |
| 최종 확인 | 2024-06-01 00:00 | 2025-03-01~2025-06-01 | 4,416 |
| 제출용 전체 재학습 | 2025-06-01 00:00 | 2025-06-01~2026-06-01 예측 | 17,520 |

`W = Σ SMP × k × |예측−실제|`, `W_pct = 100 × W / Σ(SMP × k × 실제)`이며 낮을수록 좋다. 동일 구성에서는 수익 항이 같으므로 가중 오차 감소가 로컬 점수를 높인다. 실제 공식 점수의 백분율이나 일반적인 MAPE가 아니다.

| 평가 구간 | 기존 W_pct | 새 W_pct | 변화, %p |
|---|---:|---:|---:|
| 첫 개발 | 12.695950 | **12.041604** | −0.654347 |
| 최근 개발 | 11.639887 | **11.064367** | −0.575520 |
| 전체 2024-06~2025-05 | 11.048843 | **10.716156** | −0.332687 |
| 최종 확인 2025-03~05 | **9.576119** | 9.848507 | +0.272387 |
| 엄격한 전체 발전소 기간 2025-01~05 | **9.663307** | 9.746130 | +0.082822 |
| 전체 연간 11~15시 피크 | 10.708504 | **10.416315** | −0.292189 |

전체 연간 W는 1,909,499,870.526 → 1,852,003,691.076으로 줄었다. 반대로 최종 확인 W는 473,970,621.229 → 487,452,447.625로 증가했다. 3월과 5월에 악화됐고 4월은 개선됐다. 전체 연간 수치는 개발에 사용한 최근 9개월을 포함하므로 독립된 최종 성능의 증거로 해석하면 안 된다.

일자 단위 paired bootstrap 2,000회, seed 20261104의 `새 W_pct−기존 W_pct` 95% 구간:

| 구간 | 95% 구간, %p |
|---|---:|
| 전체 연간 | [−0.542889, −0.119716] |
| 최종 확인 | [−0.166915, +0.669217] |
| 2025-01~05 | [−0.236439, +0.399701] |

이 구간은 여러 모델을 탐색한 선택 편향을 보정하지 않으며, 날짜 간 장기 상관이나 미래 기상 분포 변화를 모두 반영하지 않는다. 모든 과거 기간에는 이전 작업에서 노출된 이력이 있다. 원시 정답·예측에서 별도 코드를 통해 재계산한 결과는 `analysis_outputs/score_push_20261104/final/independent_check.json`에 있다.

## 학습 종료일 민감도 추가 진단

진행 상태: 완료. 원시 예측·정답·고정 혼합·해시·bootstrap을 메인 세션에서 독립 재계산해 통과했다.

원래 최종 확인 모델은 2024년 6월까지만 학습해 2025년 예보 제공 체계 변화 이후 데이터를 배우지 못했다. 실제 제출용 모델은 2025년 6월까지 학습한다. 이 차이의 영향을 점검하기 위해 모델·시드·가중치·특성 설계를 유지한 채 학습 종료일만 2025년 3월 1일로 옮겨, 동일한 3–5월 4,416행에서 비교한다.

기존 모델과 새 모델을 **모두 같은 종료일까지** 재학습하며 bottom-up도 새로 학습한다. 6월까지 학습한 bottom-up 예측을 과거 3–5월 검증에 재사용하지 않는다. 이 진단은 원래 결과를 본 뒤 추가했으므로 **사후 진단**이며 새로운 독립 검증이 아니다. 제출 CSV·ZIP·모델과 기존 확인 결과는 그대로 유지한다. 설정과 근거는 `analysis_outputs/score_push_20261104/deployment_check/`에 저장한다.

| 3–5월 평가의 학습 종료일 | 기존 W_pct | 새 W_pct | 변화, %p |
|---|---:|---:|---:|
| 원래 2024-06-01 | 9.576119 | 9.848507 | +0.272387 |
| 추가 진단 2025-03-01 | **9.437775** | 9.446583 | +0.008808 |

최신 데이터로 둘 다 재학습하면 차이는 작아지지만 새 후보의 우위는 확인되지 않는다. 새 W−기존 W는 +435,952.484이고 W_pct 차이의 일자 bootstrap 95% 구간은 [−0.401946, +0.377065]%p이다. 어느 쪽이 향후 더 좋을지 이 진단으로 단정할 수 없다. `deployment_check/independent_check.json`이 독립 검증 근거다.

실제 학습 모델은 pooled 5개, 발전소별 252개, 그룹 모델 15개로 총 272개다. PV011은 주간 학습 746행으로 사전 최소 기준 1,000행에 못 미쳐 pooled 예측을 사용했다. 실행 도중 원래 프로세스가 종료된 사실을 Windows OpenProcess 오류 87로 확인하고, 이미 저장된 269개 모델을 보존한 채 남은 관측소 모델 3개만 재개했다. 원래 실행의 종료 코드는 알 수 없으며 성공으로 기록하지 않았다. 재개 실행은 종료 코드 0이며 저장된 272개 모델 모두 예측 재현을 통과했다.

## 추가 GPU 연구와 변경된 자원 설정

사용자가 자원 확대와 최대한의 하드웨어 활용을 추가 요청했다. 사양은 CPU 16코어, RAM 63.32GiB, RTX 5090 Laptop GPU 24,463MiB다. 남은 관측소 모델 3개는 CPU 16스레드·BLAS 16스레드·Windows 보통 우선순위로 실제 학습했다. 각각 13.125/13.453/13.390초, 재개 구간 최대 메모리 약 1.14GiB였다. 동시 학습은 한 개를 유지한다.

기존 LightGBM은 GPU를 지원하지 않는 빌드였다. 기존 환경을 바꾸지 않고 `analysis_outputs/score_push_gpu_20261104/environment/`에 CatBoost 1.2.10 GPU 환경을 따로 만들었다. 메인 세션이 RTX 5090에서 합성 데이터 학습을 실행해 성공했다. 이는 GPU 사용 가능성 확인이며 대회 성능 결과가 아니다. CUDA 드라이버는 기존 621.14를 사용했고 별도 드라이버나 CUDA Toolkit은 설치하지 않았다.

이 GPU 환경에서 두 개의 새 모델 가설을 첫 개발/최근 개발 구간에 순차 비교했고, 조건을 통과한 모델만 3개 시드로 확장했다. 총 8개 학습과 8개 저장 모델의 정확한 추론 재현을 마쳤다. GPU 학습 자체는 비결정적 부동소수점 합산을 사용하므로 재학습의 비트 단위 일치를 약속하지 않는다.

모든 혼합 비중은 첫 개발 구간에서만 구해 최근 개발에 그대로 적용했다. 좋은 시드 하나의 결과를 최종 개선으로 선택하지 않았다. 이 연구에서 GPU 모델로 최종 확인 기간이나 제출 기간을 예측하지 않았으며, CPU 후보의 CSV·ZIP·모델도 변경하지 않았다. `analysis_outputs/score_push_gpu_20261104/independent_check.json`에서 원시 예측, 혼합 비중의 최적성, 두 구간 지표, 최종 폐기 결정과 189개 보호 파일 해시를 메인 세션이 독립 검증했다.

실제 GPU 측정 최대치는 21,065MiB VRAM(약 20.57GiB), 샘플링 사용률 45%였다. CPU 16스레드를 허용했고 동시 모델 학습은 한 개였다. 8개 학습·예측·재현 합계는 157.408초, 최대 CPU 작업 메모리는 약 1.05GiB였다. 작은 표 데이터의 알고리즘 특성상 자원을 허용해도 GPU 사용률이 계속 100%가 되지는 않는다. 근거는 GPU 연구의 `trials/*/*/seed*/gpu_samples.csv`, `runtime.json`, `evidence/EVIDENCE.md`다.

기본 GPU 모델의 개발 기간 이득이 일관되게 유지되지 않아 현재 사용 가능한 산출물은 앞서 생성한 CPU 후보다. **기존 공식 최고점 제출본을 보존하고, 새 후보는 실제 채점 전까지 실험 후보로 취급하는 것이 적절하다.**

2026-11-05 추가 검증도 완료했다. 관측소 정규화 모델의 복잡도, 학습량, 금액 기준 오차 최적화 네 가설을 사전에 고정하고, 각각 3시드·2개 개발 구간으로 총 24개 모델을 순차 학습했다. 좋은 시드만 고르지 않고 세 시드의 원시 예측 평균을 사용했다. CPU 후보와의 혼합 비중은 첫 개발 구간에서만 결정해 최근 구간에 그대로 적용했다.

두 구간 모두 개선하고 혼합 비중이 2% 이상이어야 채택한다는 기준을 네 가설 모두 통과하지 못했다. 따라서 추가 GPU 모델을 제출 예측에 섞지 않았고, 기존 CPU 후보와 공식 최고점 제출본을 그대로 보존했다. 이 결과는 이번 가설들의 한계이며 모든 가능한 모델의 최적값을 찾았다는 뜻은 아니다.

금액 가중치는 학습 기간에 한정한 `정규화 계수 × 용량 × SMP × 피크 가중치 / 학습 기간 평균(용량 × SMP × 피크 가중치)`다. 실제 SMP가 0인 세 시각에서 최근 학습의 그룹별 6행은 가중치 0을 그대로 유지했다. 이는 첫 학습 전에 입력 검증 조건을 바로잡은 것으로, 원본 프로토콜과 수정 이력을 `prefit_amendment.json`에 함께 보존했다. 가격·피크 가중치·발전량 정답을 입력 특성에 추가하지 않았다.

메인 세션의 `python submission/score_push_verify_gpu.py --refinement`가 종료 코드 0으로 통과했다. 네 비교의 원시 키·정답·금액 가중치·혼합 최적성·지표·폐기 결정, 24개 모델과 정확한 저장 후 추론 재현, 보호 파일 412개를 독립 확인했다. 근거는 `analysis_outputs/score_push_gpu_refine_20261105/independent_check.json`이다. 모든 학습 제어 프로세스의 종료 코드는 0이다. GPU 재학습의 비트 단위 일치와 새로운 공식 점수는 검증하지 않았다.

추가 24개 모델의 학습·예측·재현 시간 합계는 706.756초, 최대 CPU 작업 메모리는 약 1.07GiB였다. 실제 GPU 메모리 최대 21,065MiB, 샘플링 사용률 최대 60%를 기록했다. 앞선 8개와 합해 GPU 모델 32개를 실행했으며, CPU 16스레드와 GPU 메모리 한도 90%를 허용하되 동시 학습은 한 개로 유지했다. 사용 가능한 RAM을 채우는 것 자체는 목적이 아니므로 실제 데이터와 알고리즘이 필요로 하는 메모리만 사용했다.

## 검증과 재현

메인 세션이 원시 Parquet를 읽어 별도 `math.fsum` 지표 계산, 정확한 키·정답·기존 예측 비교, 혼합 재구성, CSV 반올림 일치, ZIP 내용, 구성 일치 및 보호 파일 해시를 확인했다. 단계별 독립 확인 결과는 연구 폴더의 `independent_*_check.json`이다.

최종 export 형식 검사도 메인 세션에서 직접 통과했다: 발전소 253개, 그룹별 용량 21,208.195/21,447.175kW, 예측 17,520행, 그룹별 8,760시간, 2025-06-01 01:00~2026-06-01 00:00 KST. 결측·무한값·음수 및 자기 그룹 용량 초과는 없다. 중복, 잘못된 그룹/시간대/시각/용량, 음수·무한값·NaN 등 9개 비정상 입력이 거부됐다. 근거는 `final/root_artifact_validation.json`이다.

최종 전체 재학습은 12개 모델을 순차 실행했고 311.797초, 최대 메모리 약 1.59GiB였다. 저장된 모델의 예측 재실행과 동결 소스 무변경 확인도 통과했다. 이는 전체 연구 소요 시간이 아니라 최종 실행 한 번의 자원 기록이다.

워크스페이스 루트에서 검증:

```text
python submission/score_push_verify_final.py
python submission/validate_artifacts.py submission/score_push_candidate --self-check
```

실행 당시 명령은 `python submission/score_push/final_execute.py`이며, `final/freeze.json`, `final/sources/`, `final/models/`, `final/REPRODUCTION.txt`에 입력·설정·소스·학습 산출물을 보존했다. 완료된 실행 폴더에 다시 학습 명령을 실행하지 않는다. 이 코드는 기존 결과를 덮어쓰는 재실행을 의도하지 않는다. 예측 검증에는 위 확인 명령을 사용한다.

SHA256:

```text
composition.csv 68216d1f6b8b6f9c026703e3bfaf7b0470cc8e018580826c866ee0f7357cc141
forecast.csv    886461035abd19c80daa021f46e17577642807c7396b528c4c95f27bedfde9a0
ZIP             31bf82fa2ec7df7329475ec695153acdc6662b99ba756d4a540cd09d8f1a8a6b
```

형식·수치 재현과 실제 리더보드 개선은 다른 주장이다. 대회 업로드·자동 제출은 하지 않았다. LSP 설치는 사용자가 원하지 않아 수행하지 않았으며 기존 소스 검사와 실행 결과로 확인했다. Git 저장소가 아니므로 commit 대신 SHA256과 소스 스냅샷으로 변경 이력을 남겼다. 수상 여부나 65억 초과 점수를 보장할 근거는 없다.

첫 GPU 실험군의 8개와 후속 실험의 24개 학습 프로세스가 모두 종료됐음을 PID·생성 시각과 Windows OpenProcess로 확인했다. 첫 전용 임시 폴더 약 124MB와 후속 전용 임시 폴더를 제거하고 경로가 남지 않았음을 확인했다. 후속 폴더는 제거 시 비어 있었다. 학습 모델·원시 예측·로그·소스 스냅샷과 별도 GPU 환경은 재현을 위해 보존했다. 정리 근거는 `analysis_outputs/score_push_20261104/cleanup_receipt.json`과 `analysis_outputs/score_push_gpu_refine_20261105/cleanup_receipt.json`이다. 전체 요구사항 감사는 `analysis_outputs/score_push_20261104/completion_audit.json`, 마지막 독립 확인은 후속 GPU 폴더의 `root_closing_checks.json`에 기록했다. 추가 GPU 후보가 채택 기준을 통과하지 못한 결과까지 포함해 이번 연구·산출물 검증과 자원 정리를 완료했다.
