## 0. 세 줄 결론

1. **승부는 예측 모델 품질에서 난다.** 검증연도(2024-06~2025-05) 기준 페널티 W를 per-site 기준선 2.815e9 → pooled 앙상블+그룹직접모델 블렌드 2.079e9로 **−26.1%** 줄였고(0.1·W 환산 약 7,360만 원/년), 그중 −22.3%는 "발전소별 모델 → 전 발전소 단일(pooled) 모델" 전환 하나에서 나왔다. 구성(composition) 레버는 전체 페널티의 **최대 2.3%**(참조 분할 기준 약 495만 원/년, 실현 기대치 150~370만 원/년)에 그친다.
2. **기상 입력은 17시 라운드, A사+B사 병용, 습도·운량(A)·UV(B)가 핵심.** 10시 라운드는 모든 변수·모든 연도에서 더 나쁘고(모델 W +5~6%), 라운드 블렌딩은 모델 수준에서 분산감소 이상의 이득이 없다. 단, **B사는 2025-01부터 라운드 간 갱신 체제가 바뀌었고 테스트 연도는 전부 새 체제**라 B-r10 피처 변형을 2025-01~05 구간으로 한 번 더 검증해야 한다.
3. **사후 보정·0 처리·캡은 최종 앙상블에 적용하지 않는다.** 검증에서 살아남은 후처리는 사실상 없다(앙상블에 전역/시간대 계수 적용 시 계절 교차에서 −1.1~−2.3%). 대신 공짜로 고칠 결함이 하나 있다: 현재 파이프라인의 "야간 = 구간 중점 고도 ≤0°" 규칙이 **박명 발전 0.10%(VAL 56,186~57,970 kWh)를 강제 0**으로 만들고 있어 W의 약 0.32~0.34%(≈69~72만 원/년)가 예측도 못 해 보고 사라진다.

## 2. 점수식 구조와 돈의 크기

### 2-1. 구조

`S = Σ_t SMP_t·actual_t − 0.10·Σ_t SMP_t·k_t·(|e_G1,t| + |e_G2,t|)`. 첫 항(수익 R)은 참가자와 무관하므로 **순위는 전적으로 W = Σ_t w_t(|e_1|+|e_2|), w_t = SMP_t·k_t 로 결정**된다. 페널티 = 0.1·W.

* 삼각부등식으로 W ≥ W_pool = Σ w|e_1+e_2|, 등호 = 매시간 두 그룹 오차 부호 일치. 초과분은 정확히 `2·Σ_t w_t·min(|e1|,|e2|)·1[sign(e1)≠sign(e2)]` (검증에서 항등식 수치 확인, 오차 ≤3.4e-7).
* 각 시각의 L1 최적 점예측은 **조건부 중앙값**이고 w_t는 알려진 상수라 예측 목표를 바꾸지 않는다. 가중치는 "어느 시각을 더 잘 맞출지"(모델 용량 배분)와 모델 선택·블렌딩 기준에만 영향.

## 6. 집합 구성(composition) 최적화 결과와 이론

### 6-1. 이론 (검증 통과)

* W ≥ W_pool, 초과분 = 2Σ_t w_t·min(|e1|,|e2|)·1[부호 불일치] → **시간별 부호 일치가 유일한 레버**. 무작위 500개 분할에서 Spearman(corr(e1,e2), gap) = **−0.887**.
* 따라서 **"분산/헤지"(지역을 나눔)는 최악, "쌍둥이 포트폴리오"(오차가 같이 움직이는 짝을 양쪽에 하나씩)가 최선**. 용량 균형은 무관(Spearman 0.001, p=0.95; 제약을 ±200 kW로 조여도 0.495% vs 0.466%).
* **전제**: W_pool이 분할 불변인 것은 그룹 예측 = 사이트 예측의 합(bottom-up)일 때만. 그룹 직접 모델(E4)을 섞으면 W_pool 자체가 구성에 따라 변하고(E4_blend50의 W_ref−W_pool은 참조 분할에서 3.4%, 6.7e7), 현재의 모든 구성 수치는 E1/E7 bottom-up 오차 기준이다.
* 레버 크기: 참조 분할의 초과분 4.95e7 = W 2.15e9의 **2.3%**. 나머지 97.7%는 예측 모델 몫. 레버 크기는 오차 구조에 종속(E1 오차 2.35% vs 기후값 오차 0.55%).

**검증이 추가한 뉘앙스(L1 단일 모델 한정)**: 학습기간 마지막 1년의 in-sample 잔차로 적합한 전역/시간대 가중 중앙값 계수("trainfit")는 새 L1/L1w 4개 모델 모두에서 **+0.98~+1.05%(전역) / +1.10~+1.23%(시간대)**, G1 계수 0.984가 학습·전반·후반에서 안정. 이는 L1 bottom-up의 구조적 G1 과대예측(5-3)을 되돌리는 것뿐이고, **E7(계수 0.995/0.980)·E4_blend50은 평균화·블렌드로 이미 그 편향이 줄어 있어 이득이 작거나 음수일 것** → 최종 앙상블에 적용하기 전에 같은 프로토콜로 재확인(미검증). 블렌드 후에는 어떤 계수도 적용하지 않는다.

**최종 권고**: 최종 앙상블에는 보정·0 처리·캡 없음. 유일하게 방어 가능한 보정은 "bottom-up L1 멤버에 한해 G1 전역 계수 ~0.975~0.984(trainfit)"이며, 그것도 블렌드 전·검증 후에만. 월(×시간) 계수의 잠재 이득(+1~1.6%, 약 300만 원)을 확인하려면 2023-06~2024-05를 검증연도로 하는 백테스트를 한 번 더 만들어 "같은 달·다른 해" 전이를 봐야 한다(현 자료로는 불가).

## 11. 남은 한계 (정직하게)

* 검증연도가 1년뿐이라 "같은 달·다른 해" 전이(실제 제출 상황)는 어떤 후처리·구성에 대해서도 직접 검증하지 못했다. half(비관)·wk(낙관) 사이로 해석.
* 학습 창은 메모리 제약으로 2년(2022-06~2024-06). 전 기간 학습 시 절대 수치는 달라질 수 있으나 실험 간 순위가 뒤집힐 근거는 없다.
* 테스트 연도 결측 실측의 채점 규칙(0 vs 제외), 동점 처리, 점수 공개 방식은 문제정의서 미확인.
* 모든 구성 수치는 bottom-up E1/E7 오차 기준. E4 블렌드 포함 최종 모델에서의 구성 이득은 미측정.
* B사 라운드 체제 전환(2025-01~) 이후의 B r17 오차 특성은 테스트 연도 실측이 없어 검증 불가. A사 2025년 skill 저하 여부도 동월 비교 전까지 미확정.
* 금액은 검증연도 SMP(0.1·W) 또는 테스트 연도 기후학적 발전량 기준이며 ±5%, 연도 라벨을 항상 확인할 것.
* 인터넷 검색(대회 규정·외부 기상 자료·타 참가자 접근법)은 어느 단계에서도 수행되지 않았다.
