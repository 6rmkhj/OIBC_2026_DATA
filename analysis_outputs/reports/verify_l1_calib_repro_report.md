## 1. 검증 설계 (원본과 독립적인 구현)

* 그룹 매핑: `sites.csv`의 current_group을 직접 사용(A→G1, B→G2). day.parquet의 current_group 열과 전 행 일치 확인.
* 가중치: `cache/smp_all.parquet`에서 w = SMP·k를 직접 계산. k 열이 "11~15시 = 3" 규칙과 전 행 일치함을 확인.
* 집계: (ts, group) 합계를 직접 groupby, 야간 행(elev ≤ 0)은 예측 0·실측 포함. W_ref = Σ w(|e_G1|+|e_G2|), Rw = Σ w·actual = 1.728e10 (8,760시간).
* 타깃: cf = energy/capacity_kw, [0, 1.2] 클립 — day.parquet의 cf 열과 일치(atol 1e-5) 확인.
* 학습/검증: 원본과 동일한 시간 분할(학습 2022-06-01 < ts ≤ 2024-06-01 주간 963,460행, 검증 2024-06-01 01:00 ~ 2025-06-01 00:00 주간 1,083,299행 + 야간 1,087,346행). 피처 24개(BASEF), LightGBM 400 trees/lr 0.06/leaves 127/mcs 200/subsample·colsample 0.8, n_jobs 10. **objective만** `regression`(L2) / `regression_l1`(L1) / `regression_l1`+sample_weight=SMP·k/mean(L1w)로 바꾸고, 시드는 원본(0, 2, 3)과 다른 **101, 202, 303**을 사용.
* 보정: 곱셈 계수 a = (w·p)-가중 중앙값(y/p) (Σw|y−a·p| 최소화), 전역/시간대별(셀 ≤ 20행이면 1). 세 가지 프로토콜 — (i) half-CV: 전반(≤2024-12-01)으로 적합→후반 적용 및 교대(원본 E5/bid_postproc과 동일), (ii) **trainfit(배포 가능)**: 학습기간 마지막 1년(2023-06~2024-06)의 in-sample 잔차로 적합→검증연도 전체에 적용, (iii) in-sample 상한.

## 6. 수정·보완 사항 (corrections)

1. "SMP·k 가중 L1" 부분은 지지되지 않는다. 가중 여부는 노이즈 범위(L1w 12.486 vs L1 12.468, n=5/3)이고 학습 시간이 4~6배이므로 **비가중 L1을 기본으로** 권고. 보고서 2절의 "가중 −1.6% vs 비가중 −1.1%"는 시드 1개 차이.
2. L2 기준선(E0_pool 12.661)은 L2 4개 시드 중 최선값이다. 기대값 기준 L1의 이득은 −1.9%(0.24pp)로 보고서(−1.1~−1.6%)보다 크다. 비교 표에는 L2도 다중 시드 평균을 쓸 것.
3. 보정 결론 재정리: 원본 E5/bid_postproc의 "보정 금지" 결론은 **L2 모델과 앙상블(E7/E4)에 대해서만** 맞다. L1 단일 모델에는 half-CV에서 +0.3%(노이즈), **학습기간 in-sample 잔차로 적합한 전역/시간대 가중 중앙값 계수는 +1.0~1.2%로 4/4 시드에서 일관**. 다만 이 trainfit 프로토콜은 단일 pooled 모델에서만 검증했으므로 최종 앙상블(E7_mix_site10, E4_blend50)에 적용하기 전에 같은 방법(앙상블 구성 모델들의 학습기간 in-sample 잔차)으로 한 번 더 확인해야 한다. 앙상블은 평균화로 G1 과대예측이 이미 줄어(E7 계수 0.995/0.980) 이득이 작을 수 있다.
4. 주장을 정량화하면: "L1 학습 −1.9% (확실), 보정 −0.3%(half-CV)~−1.1%(trainfit) 추가, 합계 L2 대비 −0.8%(최악) ~ −3.5%(최선)". 검증연도 0.1·W 환산으로 약 180만~770만 원.
