# OIBC 2026 autoresearch 성능 개선 결과

작성일: 2026-11-03. 새 제출 후보는 `submission/autoresearch_candidate/`입니다. 기존 `award_candidate/` 대비 후기 1년의 가중 절대오차가 **4.3604% 감소**했고, 전체 발전소가 갖춰진 1~5월에는 **5.4792% 감소**했습니다. 두 CSV와 ZIP을 생성했으며 대회 사이트에는 제출하지 않았습니다.

## 확인된 성능

아래 W%는 `100 × Σ(SMP × k × |예측−실적|) / Σ(SMP × k × 실적)`입니다. 작을수록 좋습니다. 공식 리더보드 백분율이나 순위가 아닙니다. `k`는 실제 타임스탬프의 11~15시에서 3, 나머지에서 1입니다.

| 평가 구간 | 이전 후보 W% | 새 후보 W% | 차이(%p) | 집합별 시각 행 수 |
|---|---:|---:|---:|---:|
| 선택용 1년 | 13.210226 | 12.695950 | -0.514276 | 17,568 |
| 후기 1년 | 11.552586 | **11.048843** | **-0.503744** | 17,520 |
| 전체 발전소 2025년 1~5월 | 10.223467 | **9.663307** | **-0.560159** | 7,248 |
| 후기 1년 11~15시 | 11.238239 | **10.708504** | **-0.529735** | 3,650 |

후기 1년의 W는 1,996,558,623.3033에서 1,909,499,870.5259로 감소했습니다. 제공된 점수 산식 `S = Σ(SMP × 실적) − 0.1 × W`에 대입하면 S는 7,297,927,624.1054에서 7,306,633,499.3832로 약 8,705,875.2777 증가합니다. **오차 4.36% 감소를 공식 점수 4.36% 상승으로 해석하면 안 됩니다.**

동일 날짜를 함께 뽑는 일 단위 paired bootstrap 2,000회(seed 20261103)의 새 후보−이전 후보 W% 차이 95% 구간은 후기 전체 **[-0.718221, -0.301553]%p**, 전체 발전소 구간 **[-0.871811, -0.275325]%p**였습니다. 이는 해당 관측 기간 내 재표본화 결과이며, 계절 간 의존성이나 실제 테스트 연도의 분포 변화를 보장하지 않습니다.

## autoresearch 적용 방식과 최종 모델

카파시의 [autoresearch program.md](https://github.com/karpathy/autoresearch/blob/228791fb499afffb54b46200aca536f79142f117/program.md)를 참고해 평가·분할·입력을 고정하고, 기준 재현 → 가설 실험 → 측정 → keep/discard 기록을 반복했습니다. 원본의 CUDA 언어모델 학습 대신 이 대회의 CPU 예측 파이프라인에 적용했습니다. Git 저장소가 없어 소스·설정의 SHA256 스냅샷을 사용했습니다.

성공 기록은 총 **50개**입니다. 기준 재현과 학습 없이 혼합 비율만 바꾼 재채점도 포함되므로 서로 다른 모델 50개를 학습했다는 뜻은 아닙니다. 주요 진행은 다음과 같습니다.

1. 기준 W% 13.210226을 정확히 재현했습니다. 오차 가중 학습, 학습량 증가, 최근 데이터 가중 등은 개선하지 못했습니다.
2. 작은 트리와 동일 예보일의 시간 변화량이 개선했습니다.
3. 예보일 내 주간 평균·표준편차, 다음 시간의 예보 변화량, 시드 평균이 추가로 개선했습니다.
4. 두 집합을 함께 학습하는 모델이 개선했습니다. 공간 분산 특징과 더 많은 반복은 최종 후보에 채택하지 않았습니다.
5. 다른 학습기 HistGradientBoosting도 비교했지만 기존 LightGBM보다 나빴습니다. 추가 반복도 악화됐습니다. 마지막으로 가중 L1 오차를 최소화하는 단일 혼합 계수를 선택 기간에서 계산했습니다. 0.7에서 최적 계수로의 추가 개선은 0.000425%p로 매우 작았습니다.

최종 직접 모델은 LightGBM L1, 31 leaves, 400 trees, learning rate 0.03, min child 50입니다. 두 집합을 함께 학습하고 집합 코드를 입력에 넣습니다. 라이브러리 기본 시드(None)와 명시적 시드 1·2의 세 모델을 순서대로 학습해 평균합니다. 설정의 0은 기본 시드를 뜻하는 표식이며, 명시적 `random_state=0`과 구분합니다.

최종 예측은 **집합 직접 모델 71.4930% + 기존 발전소별 예측 합계 28.5070%**입니다. 구성은 이전의 `inner_twins`를 유지합니다. 최종 선택 모델은 공간 특징을 사용하지 않습니다. 이미 발행된 예보의 동일 날짜 내 미래 시간 정보를 사용하며, 미래 실측 발전량을 입력하지 않습니다.

## 분할과 검증의 범위

모든 시각은 KST입니다. 선택용 학습은 `ts <= 2023-06-01 00:00`, 선택 평가는 `2023-06-01 00:00 < ts <= 2024-06-01 00:00`입니다. 이후 모델·혼합 계수·소스 해시를 고정하고 `ts <= 2024-06-01 00:00`으로 다시 학습하여 `2024-06-01 00:00 < ts <= 2025-06-01 00:00`을 평가했습니다. 이 후기 결과로 다시 조정하지 않았습니다.

최종 모델은 `ts <= 2025-06-01 00:00`의 전체 학습 데이터로 재학습했습니다. 제출 예측은 `2025-06-01 01:00`부터 `2026-06-01 00:00`까지입니다. 발전소별 예측은 동일 입력의 기존 캐시를 해시·시각·실적 일치 확인 후 재사용했습니다.

발전량 행이 없는 과거 시각을 실적 0으로 만들지 않았습니다. 과거 평가는 관측 발전소 기준이므로, 253개 발전소가 모두 있는 엄격한 `2025-01-01 00:00 < ts <= 2025-06-01 00:00` 구간 7,248행을 별도로 검증했습니다.

이번 탐색은 후기 연도로 조정하지 않았지만, **이전 모델 설계와 구성은 과거 작업에서 후기 연도를 검토한 이력이 있습니다.** 따라서 완전히 미사용인 최종 홀드아웃이라고 부를 수 없습니다. 실제 대회 테스트 정답과 리더보드 결과는 없으며, 수상 가능성이나 순위를 수치로 보장할 근거도 없습니다. 공식 문제정의서·채점 코드가 제공되지 않아 제출 횟수, 구성 변경 조건, 외부 데이터·모델 제한은 이 검증으로 확정하지 않았습니다.

- 발전소 253개, 집합별 8,760개 시각, 총 17,520개 예측을 확인했습니다.

- 중복·잘못된 시각·음수·NaN·무한대 검사를 통과했습니다. 검증기의 잘못된 입력 9가지 거부 검사도 통과했습니다.

- 후기 원시 Parquet의 점수, 월별·피크·전체 발전소 진단 30행, bootstrap을 학습 코드와 별개로 다시 계산했습니다.
- ZIP 내부 파일과 CSV 원본의 바이트 일치를 확인했습니다. 이전 제출 후보와 기존 상위 CSV는 보존했습니다.
