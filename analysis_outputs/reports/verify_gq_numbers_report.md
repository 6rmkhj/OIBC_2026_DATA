# verify_gq_numbers — 데이터 품질 주장 적대적 검증 (렌즈: numbers-in-reports / reproduce-a-key-number)

검증 대상 주장: "플래그된 발전량 이상(음수, CF>1, 야간 비영, 플랫라인, 주간 결측)은 실재하며, 제안된 정제 규칙(야간 강제 0, 음수→0, CF>1→1)은 정상 데이터를 제거하지 않는다." (`gen_quality_report.md` 3장·7장 권고 4)
스크립트: `verify_gq_numbers.py`, `verify_gq_numbers2.py`, `verify_gq_fig.py` (입력: `cache/cf_wide.parquet`, `cache/smp_all.parquet`, `sites.csv`만 사용; 태양고도는 독립 재계산). 로그: `out/vq_log.txt`, `out/vq_log2.txt`.

## 판정: 부분 반박 (refuted = true, 신뢰도 0.75)

* 이상치 **건수는 모두 재현**됨 — 음수 40건/−3.85 kWh/10개소(최소 −1.0), CF>1 9건/8개소/최대 1.034(PV104 2022-04-03 13:00), 편입 후 내부 결측 1건(PV051 2021-06-15 18:00~16일 00:00, 7시간), 진짜 야간(중점고도 ≤−6°) 비영 21,995시간/236개소/3,779.5 kWh = 전체 94,430,052 kWh의 0.0040%, 중점고도 ≤0° 비영 143,882시간 중 박명 121,887시간.
* 그러나 **"야간 강제 0" 규칙은 정상 데이터를 제거한다.** 보고서가 쓴 야간 정의(중점고도 ≤0°, 모델 파이프라인의 `elev>0` 주간 필터와 동일)로 0을 강제하면 **97,412 kWh(전체의 0.103%, w가중 0.043%)**가 지워지고, 그중 **93,633 kWh(96%)는 박명(−6°<고도≤0°) 구간의 정상 발전**이다(253개소 전부, 06~08시·18~20시, 박명 CF 중앙값 0.0047, p99 0.020, 최대 0.249). 보고서는 "3,779.5 kWh(0.0040%)"만 kWh로 제시했는데 이는 ≤−6° 밴드의 값이고, 실제 규칙이 지우는 양은 그 **25.8배**다.
* **플랫라인은 실재하는 이상이 아니라 정수 kWh 계량 양자화**다. 플랫라인 상위 12개소는 모두 14~100 kW 소형이며 양의 값의 96.5~99.2%가 정수 kWh(PV032 99.2%, 고유값 77개). 보고서의 근거("분해능 중앙값 0.002 kWh → 정오 포화 우연")는 틀렸다: 플랫 시간의 CF 중앙값은 0.10(p90 0.57, CF>0.3 비율 15.4%)으로 저출력 구간이다. 또한 보고서의 "483h/367h"는 `run>=3`(각 런의 4번째 이후 시간만 집계)이라 런 전체 시간 기준 **1,539h/1,165h**의 약 1/3이다(개소 32, 최장 8h는 일치). 결론 "무시"는 유지되나 숫자와 근거는 수정 필요.
* 실무 영향은 작다: VAL 연도 박명 발전 56,186 kWh = 연 kWh의 0.100%, Σw·actual(1.728e10)의 0.040%(6.94e6 w·kWh). 최상 모델 W 2.153e9(E1_l1w) 대비 **0.32%**, 금액으로 0.1×6.94e6 ≈ **69만 원/년**. 따라서 "규칙이 정상 데이터를 제거하지 않는다"는 문장은 틀렸지만, "무시 가능한 규모"라는 평가는 성립한다.

## 4. 수정 제안

1. 야간 규칙: `elev_mid ≤ 0` 대신 **"구간 시점·종점 모두 고도 ≤0°"(또는 `elev_mid ≤ −6°`)**로 정의. 제거량 97,412 kWh → 4,028 kWh. 모델에서는 박명 행을 학습에 포함하거나(현재 `elev>0`만 학습, 야간 pred=0), 최소한 박명 행에 포트폴리오 박명 평균 CF(≈0.005)를 예측값으로 쓰면 W 약 0.3%(≈69만 원/년) 회수 가능. 우선순위는 낮음.
2. 보고서 3.2절에 "≤0° 규칙이 지우는 kWh = 97,412(0.103%)"를 명시하고, 3,779.5 kWh는 ≤−6° 밴드 값임을 구분.
3. 3.4절 플랫라인: 시간 수를 런 전체 기준 1,539h/1,165h(CF>5%)로 정정하고, 원인을 "소형 플랜트 정수 kWh 계량 양자화"로 수정. 계량 분해능 지표는 최소 스텝이 아니라 정수/0.1 격자 비율로 보고.
4. 음수→0(+3.85 kWh), CF>1→1(−11.94 kWh)은 무해 — 유지.
