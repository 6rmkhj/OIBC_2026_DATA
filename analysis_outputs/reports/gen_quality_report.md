입력: `train/generation.parquet` (4,392,566행), `sites.csv`, 캐시 `cf_wide.parquet` (38,244시간 × 253), `smp_all.parquet`.
검증연도(VAL) = 2024-06-01 01:00 ~ 2025-06-01 00:00 KST. 태양고도는 구간 중점(ts−30분) 기준 간이 NOAA 식으로 계산(위경도는 제공된 이동 좌표).

## 0. 한 줄 요약

* 결측은 **전부 "편입 이전" 구간**이다. 전체 기간을 통틀어 내부 결측(gap)은 단 1건(PV051, 2021-06-15 18:00~00:00, 7시간)뿐이고, 편입 후 커버리지는 253개소 모두 99.98~100%다. 야간 0 kWh도 빠짐없이 기록되므로 "행 없음 = 0"이 아니라 "행 없음 = 미편입"이다.
* 따라서 테스트 연도에 결측이 생길 가능성은 역사적으로 거의 0이며, "결측을 0으로 채점"하는 규칙이 있더라도 영향은 **신규 편입/탈락 발전소**에서만 나온다. VAL 연도에 그 규칙을 적용했다면 가중 페널티는 수익의 0.98%(7.35e7원 / 7.50e9원), 전부 2024-06~08에 편입된 48개소에서 발생.
* 데이터 이상(음수 40건, CF>1 9건, 플랫라인 367시간, 심야 발전 3,780 kWh)은 모두 **무시 가능한 규모**다. 진짜 리스크는 (a) 이력 1년 미만 48개소 9,491 kW(B그룹에 8,292 kW 집중), (b) 만성 저성능·간헐 정지 대형 발전소(PV004 1,388 kW, PV188 992 kW, PV011 1,276 kW, PV108 850 kW), (c) 그룹 A에 몰린 열화 발전소 12개소다.
* 포트폴리오 kWh의 65.5%가 ts 11~15시에 들어오지만 **SMP·k 가중치로는 84.9%**가 이 5시간에 집중된다.

## 6. "테스트 연도 결측을 actual=0으로 채점한다면" 정량화 (VAL 연도 기준)

기대 발전량 프록시 = 포트폴리오 용량가중 CF × 해당 발전소 용량.

| 항목 | 값 |
|---|---|
| VAL 결측 (site,ts) / 주간 | 45,635 / 27,774 |
| 결측 0인 발전소 | 205개소; 주간 결측 >5%: 45개소, >20%: 3개소(PV011 57.9%, PV021 28.8%, PV167 27.2%) |
| 결측 슬롯 기대 kWh | 2,398,168 kWh = 보고된 56,411,884 kWh의 **4.25%** |
| w-가중 | 7.35e8 / 1.73e10 = 4.25% |
| 완벽 예측 + 결측=0 채점 시 페널티 | 0.1 × 7.35e8 = **7.35e7원 = 수익(Σ SMP·actual 7.50e9원)의 0.98%** |
| 그룹별 기대 결측 비중 | A 0.63%, B **7.26%** |
| 집중도 | 상위 5개소 69.7%, 상위 10개소 78.0%, 상위 20개소 86.6% |
| 월별 | 2024-06 1.21M kWh, 07 0.48M, 08 0.26M, 09~12 0.09~0.14M, 2025-01~05 0 |

해석: 이 4.25%는 전부 "편입 전"이고 2025-01 이후 0이므로, 테스트 연도(2025-06~)에는 **같은 종류의 결측이 재현될 근거가 없다**. 테스트 연도 결측 리스크는 (i) 발전소 탈락/해지, (ii) 신규 통신 장애 두 가지인데 훈련 4.4년 동안 (ii)는 7시간뿐이었다. 그래도 보수적으로 보면, 결측을 0으로 채점하는 규칙 아래서는 **대형 발전소가 한 달 빠지면 그 그룹 페널티가 그 달 수익의 수 %** 수준이므로(PV011 1개소만으로 VAL 총 w-결측의 41%), 대형 발전소를 두 그룹에 분산하는 것이 분산 효과가 크다. 표: `gq_site_missing_val_year.csv`, 그림: `gq_fig05_missing_val_year.png`.
