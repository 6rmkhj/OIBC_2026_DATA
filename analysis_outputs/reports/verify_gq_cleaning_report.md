# verify_gq_cleaning — gen_quality 이상치·정제 규칙 적대적 검증 (렌즈: 핵심 수치 재현)

검증 대상 주장: "플래그된 발전량 이상(음수, CF>1, 야간 비영, 플랫라인, 주간 결측행)은 실재하며, 제안된 정제 규칙은 정상 데이터를 제거하지 않는다."

## 2. 핵심 수치: "야간 강제 0" 규칙이 실제로 지우는 발전량

핵심 사실:
* 실제 규칙(중점 ≤ 0°)이 지우는 발전량은 **97,412 kWh**로, 보고서가 근거로 든 3,779.5 kWh의 **25.8배**다. 그중 **95.9%(93,384 kWh)는 구간 시작이나 끝에 해가 지평선 위에 있는 "부분 일조 시간"**의 출력이다 — 계측 잡음이 아니라 물리적으로 정상인 발전이다.
* 중점 고도 1° 밴드별 에너지가 −6°→0°→+1°로 1,987 → 4,199 → 11,652 → 15,593 → 27,217 → 32,986 → 42,198 kWh로 **연속적으로 증가**하며 0°에서 불연속이 없다(`out/vgq_elev_band_energy.csv`, 그림 `out/vgq_fig_elev_band_energy.png`). 즉 0°는 물리적 경계가 아니라 임의의 절단선이다.
* 지워지는 시간 중 CF ≥ 1%인 시간이 19,495h(28,274 kWh), CF ≥ 5%가 296h. 일몰측(시작에 해 있음) 57,078 kWh > 일출측(끝에 해 있음) 36,306 kWh.
* VAL 연도 기준 개소별로 연간 발전량의 중앙값 0.12%, 최대 0.211%(PV108, 2,155 kWh/480h)가 강제 0으로 사라진다. 그룹별 VAL 손실: A 25,824 kWh / B 32,147 kWh (`out/vgq_site_zeroed_val.csv`).

점수 영향(VAL 연도, 스크립트 수치에서 유도): 강제 0은 그 시간의 오차 |e| = actual 이므로 w-가중 오차 기여 = 0.0415% × 1.7282e10 = 7.17e6 w-kWh → 페널티 0.1 × 7.17e6 ≈ **7.2e5 원/년**. model_validation 보고서의 최상 모델 W/rev 12.44%와 비교하면 전체 페널티의 약 **0.33%**(0.0415/12.44)에 해당한다. 작지만 공짜로 없앨 수 있는 체계적 과소예측이며, composition 보고서가 유의미하게 다루는 구성 간 차이(0.1×6.1e5 ≈ 6만 원)보다 한 자릿수 크다.

## 3. 다른 정제 규칙

* 음수 → 0: 제거량 −3.85 kWh(40건, 전부 05~07시·19시 박명 시간대의 −0.0025/−0.1/−1.0 kWh 오프셋). 정상 데이터 제거 없음.
* CF>1 → 1: 제거량 11.94 kWh(9건). 정상 데이터 제거 없음.
* 플랫라인·주간 0·결측: 보고서는 정제 대상으로 삼지 않았으므로(무시 권고) 제거되는 데이터 없음. 카운트는 재현됨.

## 4. 판정

* **refuted = true (confidence 0.7)** — 단, 좁은 의미에서다. 이상치 카운트는 모두 정확하고, 음수/CF>1 클리핑은 무해하다. 그러나 "야간 강제 0" 규칙은 보고서가 근거로 든 수치(3,779.5 kWh, ≤ −6°)가 아니라 실제 구현(≤ 0°, 중점 기준)으로 평가해야 하고, 그 규칙은 **정상적인 부분 일조 시간 발전 93,384 kWh(VAL 56,043 kWh, 전체 발전량의 0.10%, w-가중 0.04%)를 제거**한다. "정제 규칙이 정상 데이터를 제거하지 않는다"는 문장은 그대로는 성립하지 않는다.
* 영향 규모는 작다(최상 모델 페널티의 ~0.33%, ≈7.2e5 원/년). 그러므로 "우승 전략을 뒤집는" 결함은 아니지만 수정 비용이 거의 0이다.

### 수정 권고
1. gen_quality 보고서 3.2절·7절 권고 4의 근거 수치를 교체: "야간(중점 ≤ 0°) 강제 0 시 제거 발전량 97,412 kWh(0.103%, VAL 57,970 kWh, w-가중 0.042%), 이 중 ≤ −6° 진짜 야간은 3,779.5 kWh뿐".
2. 모델링(model_validation.py:74-75, 추론 코드 동일): 학습 제외·예측 0 마스크를 `elev_mid <= 0`에서 **`elev_start <= 0 & elev_end <= 0`(한 시간 내내 어두움)**로 바꾸면 강제 0 손실이 4,028 kWh(0.0043%, w 0.0019%)로 줄고, 박명 행 121,016개(학습 구간에선 그 일부)를 모델이 직접 학습한다. 더 간단한 대안: 마스크는 두고 `−6° < elev_mid ≤ 0` 행에 사이트×월×시간대 평균 CF(≈0.5~2%)를 채워 넣는 사후처리.
3. 피처 측면: 시간 구간 내 일조 비율(해가 떠 있는 분 수/60)을 피처로 추가하면 박명 시간의 체계적 편향을 모델이 흡수할 수 있다(toa·cosz는 중점 값이라 0이 되어 정보가 사라짐).
4. 보고서의 "0 kWh 행 46.3%"는 개소별 중앙값임을 명시(풀링 값은 48.0%).
