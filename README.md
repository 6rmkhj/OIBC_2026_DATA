## 무엇을 바꾸며 실험하는가

**현재는 기존 발전량 모델의 예측에 보정을 더하는 단계입니다.** 앞선 `c000~c255`는 발전량 모델 자체의 입력·학습 방식을 비교했고, 연장 `n0000~n2047`은 그중 고정한 32개 기초 모델(`b00~b31`)마다 64개 보정 설정(중앙값 4개·트리 60개)을 비교합니다. ID는 고정된 실행 큐의 번호이며, 번호가 커진다고 모델이 누적 개선되는 것은 아닙니다.

1. **발전량 모델**: 날씨·태양고도 등의 입력에서 기초 예측을 만듭니다. 예: `b00`은 앞선 `c206` 설정입니다.
2. **오차 보정**: 학습 마감일 이후에 만든 과거 예측(시간 순서 OOF)의 오차를 배워 기초 예측에 제한된 보정량을 더합니다.
3. **최고 제출 모델과 혼합**: 보정 예측에 가중치 `alpha`, 기존 최고 예측에 `1-alpha`를 줍니다. `alpha`는 primary에서만 정하고 recent에는 그대로 적용합니다.

**각 행의 결과는 동일한 설정을 5개 학습 마감일에서 평가한 값입니다.** 일부 설정은 함께 바뀌는 조합 탐색입니다. 그 경우 점수 차이를 한 변수의 효과로 단정하지 않습니다. 가능한 모든 조합을 평가한 완전요인실험은 아닙니다. 아래 설명은 기존 설정과 저장된 결과를 읽어 생성하며 새 학습·후보 선택을 하지 않습니다.

## 성능 숫자 읽는 법

- **W / W_pct는 낮을수록 좋은 내부 오차 지표**입니다. `W = Σ(SMP × 벌점계수 × |예측−실적|)`, `W_pct = 100 × W / Σ(SMP × 벌점계수 × 실적)`입니다. 같은 기간의 W 상대 변화와 W_pct의 퍼센트포인트 차이를 구분합니다.
- 다섯 기간 평균 W/c000는 각 기간의 비율을 평균한 값입니다. 기간 전체를 합친 오차율이 아닙니다.
- `c000`은 단일 모델 비교용 기준입니다. **c000 대비 개선률은 기존 최고 제출 모델 대비 개선률이 아닙니다.**
- primary에서 정한 혼합 계수를 recent에 그대로 적용합니다. 후보별로 계수를 따로 정하므로 혼합 비교에는 계수 변화도 포함됩니다. 다섯 시점의 안정성 기준·최소 혼합 계수·두 기간의 개선 조건을 함께 통과해야 적격 후보가 됩니다. primary/recent 두 열만으로 적격을 판단하지 않습니다.
- 모든 과거 기간은 이미 노출된 자료이며 평가 기간도 겹칩니다. 독립적인 미사용 홀드아웃이나 새 공식 리더보드 점수로 해석할 수 없습니다.
