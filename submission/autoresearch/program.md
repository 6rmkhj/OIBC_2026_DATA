# OIBC autoresearch program

Adapted from Karpathy autoresearch commit 228791fb499afffb54b46200aca536f79142f117. This CPU tabular task uses immutable preparation/evaluation and mutable `train.py` plus JSON configurations. No Git repository is available: each trial records source and configuration SHA256, parent ID, hypothesis, source snapshot, model files, forecasts, metrics, runtime and keep/discard/crash decision instead of commits.

Run `python submission/autoresearch/prepare.py` once, then `python submission/autoresearch/evaluate.py --self-check` and `python submission/autoresearch/run.py wave`. A later independent proposal is `python submission/autoresearch/run.py path/to/config.json`; multiple paths execute sequentially. Never run multiple orchestrators against the same ledger.

The frozen inner_twins assignment, observed targets and five-seed bottom-up predictions are reused by content hash. Training ends 2023-06-01 KST; selection is (2023-06-01, 2024-06-01]. Outer labels are excluded during parquet loading. Prediction features exclude energy/cf/target columns. Night direct predictions are zero; absent target site rows are excluded rather than filled. Official selection W=sum(SMP*k*absolute group error); W_pct divides by sum(SMP*k*observed generation). Keep strictly smaller W; monthly and half-year diagnostics inform subsequent hypotheses, without imposing new month-wise constraints.

Resource protocol: sequential preparation and, from wave four completion onward, one subprocess trial at a time, each two LightGBM threads; BLAS/MKL/NumExpr one thread. The user requested this sequential default after the final parallel batch. Historical frozen preparation metadata records the previous maximum of two concurrent trials; the current operational limit is separately versioned in `resource_policy.json`, without altering scientific data/evaluator hashes. Workers run hidden at below-normal Windows priority. A 600-second subprocess deadline kills and reaps a slow trial, so every individual fit also remains below that ceiling. Trial workers only load compact aggregates. No GPU or dependency installs.

Mutable Config fields: id, parent_id, hypothesis; n_estimators=400, learning_rate=.03, num_leaves=31, min_child_samples=50, objective=regression_l1 (or regression_l2), weighting=none (or capacity/scored), recency_days=0 (exponential half-life days), direct_weight=.5. First reproduce baseline within 1e-5 percentage points. Alter primarily one factor, preserve best, propose next hypotheses from measured feedback. Final blending can use .25/.5/.75 only after evidence warrants it. Never read/evaluate outer results until the root explicitly locks a winner. No final submission is written by this experiment engine.

Historical baseline and composition have already been explored; this is an adaptive selection experiment, not a pristine holdout claim. Initial wave stops after nine baseline/weight/tree/objective/recency trials and returns feedback for the next decision.

Second-wave mutable extensions: `feature_mode="ramps"` appends backward one-hour differences of wa_cloud, wb_cloud, wb_uv_idx, toaa, toab and wa_temp within group and target day `(ts-1h).floor(D)`. Missing preceding daylight hours and day boundaries remain NaN. No label-derived input is used. `seeds=[0,1,2]` averages sequentially fitted direct CF forecasts before clipping and capacity multiplication. Here zero is explicitly a sentinel for the original omitted LightGBM seed (`random_state=None`), not explicit `random_state=0`. The latter failed the reproduction gate and is preserved as `w2_baseline` with its original source; `w2_baseline_default` reproduces exactly. `predict_frames(train,selection,config)` supports later split-specific fitting without changing the locked evaluator.

Blend-only proposals run `python submission/autoresearch/rescore.py SOURCE_TRIAL_ID CONFIG.json`. They preserve source forecasts and source hash, explicitly record no model fit, and journal through the same fixed evaluator. Only direct_weight and proposal metadata may differ from the parent configuration.
