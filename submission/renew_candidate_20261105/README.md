# 재검증 후보 제출 파일

기존 CPU 예측에 반감기 180일 시계열 모델을 고정 비율로 혼합한 뒤, 고정된 기온·적설 보정을 적용했습니다. 조합은 기존 253개 발전소 배정과 바이트 단위로 동일합니다.

forecast.csv는 17,520개 그룹·시간 예측을 소수 셋째 자리까지 기록합니다. submission_files.zip에는 composition.csv와 forecast.csv만 포함됩니다.

보정 계수는 개발 기본 구간에서만 추정했습니다. 해당 구간 개선은 일부 표본 내 보정 효과이며, 모든 과거 구간은 이미 노출된 개발 데이터입니다. 2025년 3~5월 결과는 설명용 진단으로만 기록했고 모델·계수 재선택에 사용하지 않았습니다. 실제 대회 점수나 업로드 성공을 주장하지 않습니다.

전체 재현 정보와 진단 결과는 manifest.json 및 analysis_outputs/renew_20261105/final/에 있습니다. 기존 제출 후보는 변경하지 않았습니다.
