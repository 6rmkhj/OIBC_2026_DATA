# OIBC 2026 제출 후보

제출 파일은 `composition.csv`와 `forecast.csv`입니다. 반드시 이 폴더의 두 파일을 함께 사용하세요. `submission_files.zip`은 두 CSV만 담은 편의용 압축 파일입니다. 공식 제출 화면이 개별 CSV를 요구하면 압축을 풀어 제출하세요.

253개 발전소, 집합별 8,760시각, 총 17,520개 예측을 검증했습니다. 용량은 G1 21,208.195 kW, G2 21,447.175 kW입니다. 구성과 직접 모델 비중 50%는 이전 연도에서 선택했습니다.

후기 1년 내부 가중 오차율은 11.5526%, 참조 구성의 동일 모델은 11.8816%였습니다. 이 값은 공식 리더보드 점수나 수상 보장이 아닙니다. 기존 모델 설계가 후기 연도에서 검토된 이력이 있어 완전히 미사용인 홀드아웃이라는 주장도 하지 않습니다.

실행 방법은 상위 폴더 `README.md`, 상세 검증 결과는 `../../analysis_outputs/reports/수상도전_파이프라인_검증보고서_20261102.md`를 참고하세요. `manifest.json`에는 선택 설정과 출력 해시가 있습니다. 기존 제출 CSV는 상위 `submission/`에 그대로 남아 있습니다.
